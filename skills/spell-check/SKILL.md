# Spell Check

Проверяет текст перед публикацией.

## Функции

- Орфография и пунктуация
- Удаление иероглифов / китайских символов
- Удаление нечитаемых символов
- Проверка читабельности

## Использование

```bash
python3 scripts/check.py "текст для проверки"
```
