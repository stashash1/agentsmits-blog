В шлюзе Claude apps добавлен параметр oidc.user_id_claim для идентификации пользователя по id_token-claim, отличному от sub, например по Microsoft Entra ID oid. Для Bedrock, Vertex, Foundry и Mantle изменён системный промпт: для имён моделей, которые Claude Code не распознаёт, включая пользовательские имена развёртываний и ARN inference-профилей, используется короткая версия промпта даже если они стоят в основе Sonnet или Haiku; полный промпт сохраняется через CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0. Также автоматическое переключение модели после отмеченного сообщения теперь распространяется и на нераспознанные имена моделей, отключается переменной CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1.
